# Queen's Knights Robotics Team

The official website for the Queen's Knights Robotics Team, deployed at
[qkrt.gabelynch.com](https://qkrt.gabelynch.com).

## Prerequisites

- Node.js `>=22.13.0`

## Quick Start

```bash
npm install
npm run dev
npm run build
npm run deploy
```

## Useful Commands

- `npm run dev`: start local development
- `npm run build`: create a production build
- `npm start`: serve the production build
- `npm run deploy`: build and deploy the production site to Cloudflare Pages
